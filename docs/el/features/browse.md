# Περιήγηση ταινιών και σειρών

Η σελίδα Περιήγηση είναι ο εξερευνητής της βιβλιοθήκης σας: κάθε τίτλος στις βιβλιοθήκες που μπορεί να ανοίξει ο λογαριασμός σας, με λεπτομερή φίλτρα, ταξινόμηση, αποθηκευμένα φίλτρα και μια καρτέλα Πρόσωπα.

## Η διάταξη της σελίδας

### Καρτέλες

- **Ταινίες** — η βιβλιοθήκη ταινιών σας
- **Σειρές** — η βιβλιοθήκη σειρών σας
- **Πρόσωπα** — κάθε ηθοποιός, σκηνοθέτης, σεναριογράφος και δημιουργός στη βιβλιοθήκη σας, με αναζήτηση, ταξινόμηση κατά Συμμετοχές (σε πόσους τίτλους εμφανίζονται, με τους περισσότερους πρώτα — η προεπιλογή) ή Όνομα, και δικό της τρόπο πλέγματος/λίστας (τα Πρόσωπα ξεκινούν σε **λίστα**)

Κάθε καρτέλα κρατά τα δικά της φίλτρα, την ταξινόμηση και τον τρόπο εμφάνισης (δείτε την [Προβολή πλέγματος και λίστας](grid-list-views.md)).

### Η μπάρα φίλτρων

Μια μπάρα που μένει σταθερή πάνω από το πλέγμα έχει, από αριστερά προς τα δεξιά: ένα **πεδίο αναζήτησης**, **Είδος**, **Franchise** (ταινίες) ή **Κανάλι** (σειρές), **Χώρα**, **Φίλτρα**, **Ταξινόμηση** και **Αποθηκευμένα**. Οι ενεργές επιλογές εμφανίζονται ως ενδείξεις κάτω από τη μπάρα, που μπορείτε να αφαιρέσετε.

Το **πεδίο αναζήτησης** φιλτράρει την τρέχουσα καρτέλα με βάση τον τίτλο καθώς πληκτρολογείτε.

## Το παράθυρο φίλτρων

Το κουμπί **Φίλτρα** (δείχνει έναν αριθμό όταν κάτι είναι ενεργό) ανοίγει όλο το πάνελ, οργανωμένο σε ενότητες. Τα περισσότερα φίλτρα είναι **ρυθμιστικά εύρους με δύο λαβές** — ορίζετε και κατώτατο και ανώτατο όριο:

| Ενότητα | Φίλτρα |
|---------|---------|
| **Βαθμολογίες** | Βαθμολογία κοινού, βαθμολογία κριτικών του Rotten Tomatoes, Metacritic |
| **Έτος** | Εύρος χρονιάς κυκλοφορίας |
| **Αν το έχετε δει** | Αδιάφορο / Το είδα / Δεν το είδα — ιδωμένο σημαίνει ότι τελειώσατε την αναπαραγωγή του· ένας τίτλος που απλώς βάλατε στα αγαπημένα, ή που σταματήσατε στη μέση, μετράει ως μη ιδωμένος |
| **Κοινό** | **Ελάχιστοι/μέγιστοι θεατές** — πόσοι διαφορετικοί χρήστες του διακομιστή σας τον έχουν παίξει |
| **Διάρκεια** | Εύρος διάρκειας (ταινίες) |
| **Ποιότητα εικόνας** | Αναλύσεις / μορφές που υπάρχουν στα αρχεία σας |
| **Σεζόν** | Εύρος πλήθους σεζόν (σειρές) |
| **Κατάσταση** | **Σε εξέλιξη / Ολοκληρωμένη** (σειρές) |
| **Καταλληλότητα** | Σήματα καταλληλότητας για ηλικίες |

Η κεφαλίδα του παραθύρου έχει ένα **εικονίδιο επαναφοράς** που καθαρίζει τα πάντα μαζί· οι ενδείξεις σάς αφήνουν να αφαιρέσετε μεμονωμένα φίλτρα.

### Χώρα

Το κουμπί **Χώρα** ανοίγει δικό του παράθυρο για τη **χώρα παραγωγής**, με πεδίο αναζήτησης και μια λίστα που ταξινομείτε **Α–Ω** ή κατά **Περισσότεροι τίτλοι**. Διαλέξτε μία ή περισσότερες χώρες:

- **Ταίριασμα** — **Οποιαδήποτε (Ή)** για «Γαλλία ή Ιαπωνία», **Όλες (ΚΑΙ)** για «Γαλλία και Ιαπωνία»
- **Με δευτερεύουσες χώρες** — απενεργοποιημένο (η προεπιλογή), ένας τίτλος μετράει μόνο για τη χώρα από την οποία προέρχεται: τη χώρα προέλευσής του, ή την πρώτη χώρα παραγωγής του όταν αυτή δεν είναι γνωστή. Ενεργοποιημένο, μετράει και κάθε χώρα συμπαραγωγής, οπότε μια γαλλογερμανική συμπαραγωγή εμφανίζεται και στη Γερμανία

Η χώρα παραγωγής είναι σχεδόν πάντα συμπληρωμένη (σε αντίθεση με τη γλώσσα), οπότε είναι ο αξιόπιστος τρόπος για να περιηγηθείτε στον κινηματογράφο μιας χώρας.

### Franchise / Κανάλι

Οι ταινίες μπορούν να περιοριστούν σε μία **συλλογή** (franchise)· οι σειρές σε ένα **κανάλι**, που το διαλέγετε από λίστα με αναζήτηση, ταξινομημένη Α–Ω ή κατά **Περισσότερες σειρές**. Για τη συνολική εικόνα των συλλογών σε όλη τη βιβλιοθήκη σας, δείτε τη σελίδα [Franchise](franchises.md).

## Ταξινόμηση

Το μενού **Ταξινόμηση** περιλαμβάνει:

| Ταινίες | Σειρές |
|--------|--------|
| Τίτλος | Τίτλος |
| Έτος | Έτος |
| Ημερομηνία κυκλοφορίας | Ημερομηνία κυκλοφορίας |
| Βαθμολογία | Βαθμολογία |
| Βαθμολογία RT | Βαθμολογία RT |
| Metacritic | Metacritic |
| Διάρκεια | Σεζόν |
| **Προστέθηκαν πρόσφατα** | **Προστέθηκαν πρόσφατα** |

Κάθε καρτέλα θυμάται τη δική της ταξινόμηση, συγχρονισμένη με τον λογαριασμό σας.

## Αποθηκευμένα φίλτρα

Οποιοσδήποτε συνδυασμός φίλτρων μπορεί να αποθηκευτεί από το μενού **Αποθηκευμένα**:

- **Αποθήκευση των τρεχόντων φίλτρων** — δώστε όνομα στον συνδυασμό και μπαίνει στο μενού
- **Διαχείριση** — μετονομασία και διαγραφή
- Η εφαρμογή ενός αποθηκευμένου συνδυασμού αντικαθιστά τα ενεργά φίλτρα· οι ενδείξεις δείχνουν ακριβώς τι περιέχει
- Τα αποθηκευμένα φίλτρα είναι ανά λογαριασμό και λειτουργούν και στις δύο καρτέλες

## Πώς διαβάζετε τα αποτελέσματα

**Προβολή πλέγματος** — αφίσες με επικαλύψεις: σημάδι ότι το είδατε, η βαθμολογία σας όταν περνάτε τον δείκτη, ένδειξη προόδου επεισοδίων για τις σειρές, βαθμολογία κοινού. Κάτω από κάθε αφίσα, το **Περισσότερα** ανοίγει την πλοκή· ανοίγει μαζί τις πλοκές όλης της σειράς αφισών, ώστε η σειρά να μένει ομοιόμορφη.

**Προβολή λίστας** — η αφίσα δίπλα στα στοιχεία:

- Τίτλος, χρονιά, **βαθμολογία κοινού**
- **Είδη** (έως τέσσερα)
- Μια **περίληψη** δύο γραμμών (με το «Προβολή στο TMDb» δίπλα)
- Η βαθμολογία σας, στη γραμμή· οι σειρές προσθέτουν την **κατάσταση** (Σε εξέλιξη/Ολοκληρωμένη) και το **πλήθος σεζόν**, μαζί με έναν διακόπτη **Το παρακολουθώ**

Τα αποτελέσματα φορτώνουν συνεχώς καθώς κυλάτε, με ένα μήνυμα στο τέλος όταν τελειώσουν όσα ταιριάζουν.

### Όταν επιστρέφετε

Η καρτέλα, η αναζήτηση, τα φίλτρα και η ταξινόμησή σας κρατιούνται στη διεύθυνση της σελίδας. Ανοίξτε έναν τίτλο και πατήστε **Πίσω**, και η Περιήγηση επιστρέφει ακριβώς όπως την αφήσατε, στο σημείο όπου είχατε κυλήσει. Μπορείτε επίσης να βάλετε σελιδοδείκτη ή να μοιραστείτε μια φιλτραρισμένη προβολή με τη διεύθυνσή της.

## Συμβουλές

- **Το «αν το έχετε δει» είναι φίλτρο** — «Δεν το είδα + RT 80%+» είναι η πιο γρήγορη σύντομη λίστα στην εφαρμογή
- **Αποθηκεύστε την προεπιλεγμένη σας περιήγηση** (π.χ. όσα δεν είδατε, ταξινομημένα κατά Προστέθηκαν πρόσφατα) και εφαρμόστε την με ένα κλικ
- **Χώρα, όχι γλώσσα** — χρησιμοποιήστε τη χώρα παραγωγής για να περιηγηθείτε στον κινηματογράφο μιας χώρας
- Οι **ελάχιστοι/μέγιστοι θεατές** βρίσκουν κρυμμένα διαμάντια (χαμηλά) ή επιτυχίες του σπιτιού (ψηλά)
