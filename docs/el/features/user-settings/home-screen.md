# Αρχική οθόνη Emby

Στο Emby, το Aperture μπορεί να προσθέσει σειρές στη δική σας **αρχική οθόνη στο Emby**: τις προτάσεις σας, τα «Πιο πολυπαιγμένα πρόσφατα» του διακομιστή, όσα σας πρότειναν οι συνδέσεις σας, και λίστες που επιλέγετε. Η καρτέλα **Αρχική οθόνη Emby** των ρυθμίσεών σας είναι το μέρος όπου βλέπετε αυτές τις σειρές, απενεργοποιείτε όποια θέλετε, και αποφασίζετε πού θα εμφανίζονται.

## Πώς την ανοίγετε

Πατήστε το **avatar** σας στην επάνω μπάρα, ανοίξτε τις ρυθμίσεις σας και επιλέξτε την καρτέλα **Αρχική οθόνη Emby**. Υπάρχει μόνο για λογαριασμούς Emby. Αν ο διαχειριστής σας δεν έχει ενεργοποιήσει τις σειρές της αρχικής οθόνης, η καρτέλα το λέει και δεν υπάρχει τίποτα να ρυθμίσετε.

---

## Πώς λειτουργούν οι σειρές

Οι σειρές δείχνουν τους τίτλους που ήδη υπάρχουν στη βιβλιοθήκη σας, οπότε τίποτα δεν αντιγράφεται: όταν παίζετε κάτι από μια σειρά, παίζει το πραγματικό αρχείο και σημειώνεται ως ιδωμένο όπως πάντα. Θα τις βρείτε σε κάθε εφαρμογή του Emby στην οποία συνδέεστε (τηλεόραση, κινητό, web), δίπλα στις δικές σας σειρές του Emby.

Οι τίτλοι μέσα σε μια σειρά ταξινομούνται με ένα πεδίο που επέλεξε ο διαχειριστής σας (τυχαία, κατά τίτλο, πρόσφατα προστιθέμενα κ.λπ.), όχι με τη σειρά των προτάσεων, γιατί το Emby δεν μπορεί να κρατήσει δική μας σειρά μέσα σε μια σειρά της αρχικής οθόνης.

---

## Οι σειρές

| Σειρά | Τι περιέχει |
|-----|--------------|
| **Πιο πολυπαιγμένα πρόσφατα: Ταινίες** / **Πιο πολυπαιγμένα πρόσφατα: Σειρές** | Οι πιο πολυπαιγμένοι τίτλοι του διακομιστή αυτή τη στιγμή· η ίδια λίστα για όλους (δείτε τα [Πιο πολυπαιγμένα πρόσφατα](../top-picks.md)) |
| **Προτάσεις ταινιών** / **Προτάσεις σειρών** | Οι δικές σας επιλογές, από την τελευταία δημιουργία προτάσεων (δείτε τις [Προτάσεις μου](../recommendations.md)) |
| **Προτάσεις από φίλους** | Τίτλοι που σας έστειλαν οι συνδέσεις σας στο [Δείτε το](../watch-this.md)· ένας τίτλος φεύγει όταν τον τελειώσετε ή τον απορρίψετε |
| **Δημιουργημένες λίστες αναπαραγωγής** | Κάθε λίστα ή συλλογή που δημιουργήσατε, ή λίστα που φτιάξατε από προτάσεις του βοηθού, και την ενεργοποιήσατε, γίνεται δική της σειρά |

Ο διαχειριστής σας αποφασίζει ποια είδη σειρών υπάρχουν και πώς λέγονται. Κάθε κάρτα στην καρτέλα λέει αν η σειρά βρίσκεται στην αρχική σας οθόνη, πόσους τίτλους έχει, και δείχνει μια λωρίδα από αυτούς. Μια σειρά που δεν μπορεί να φτάσει σε εσάς λέει γιατί: την απενεργοποίησε ο διαχειριστής σας, οι προτάσεις είναι απενεργοποιημένες για τον λογαριασμό σας, δεν υπάρχει βιβλιοθήκη αυτού του είδους που μπορείτε να ανοίξετε, ή δεν έχει τίποτα ακόμη (θα εμφανιστεί μόλις έχει).

## Ενεργοποίηση και απενεργοποίηση σειρών

Κάθε σειρά έχει έναν διακόπτη για να εμφανίζεται στην αρχική σας οθόνη. Η επιλογή σας κρατιέται ακόμη κι όταν η σειρά δεν είναι διαθέσιμη, οπότε αν ο διαχειριστής σας την ενεργοποιήσει ξανά αργότερα, μένει απενεργοποιημένη για εσάς.

Για τις λίστες, η κάρτα δείχνει κάθε λίστα που μπορεί να μπει στην αρχική σας οθόνη· ενεργοποιήστε όσες θέλετε. Μια λίστα που δεν έχει δημιουργηθεί ακόμη πρέπει πρώτα να δημιουργηθεί στη σελίδα [Λίστες](../playlists.md). Μπορείτε επίσης να επιλέξετε να εμφανίζεται στην αρχική σας οθόνη στο Emby από την ίδια τη λίστα.

## Πού θα εμφανίζονται οι σειρές

Κάθε είδος σειράς ακολουθεί την προεπιλεγμένη θέση του διαχειριστή σας μέχρι να επιλέξετε **Δική μου θέση**:

- **Πάνω** ή **Κάτω** στην αρχική σας οθόνη
- Ένας **αριθμός θέσης** (πόσες από τις δικές σας σειρές βρίσκονται από πάνω, 0 = στην κορυφή)
- **Μετά** ή **πριν** από μία από τις σειρές που ήδη έχετε, όπως το Continue Watching

Πατήστε **Εφαρμογή**. Οι αλλαγές φτάνουν στο Emby αμέσως· αν το Emby δεν απαντά, αποθηκεύονται και εφαρμόζονται στον επόμενο συγχρονισμό. Μια σειρά μετακινείται μόνο όταν δημιουργείται για πρώτη φορά ή όταν αλλάζει η θέση της, οπότε αν τη σύρετε κάπου αλλού στο Emby, μένει εκεί που τη βάλατε.

## Η προεπισκόπηση

Η **αρχική οθόνη σας στο Emby** δείχνει όλη την αρχική σας οθόνη από πάνω ως κάτω, όπως θα είναι με τις επιλογές σας. Οι σειρές του Aperture είναι τονισμένες· οι υπόλοιπες είναι οι δικές σας σειρές του Emby.
