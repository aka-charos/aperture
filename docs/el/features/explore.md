# Χάρτης περιεχομένου

Ο Χάρτης περιεχομένου (πλαϊνό μενού: **Χάρτης περιεχομένου**, εικονίδιο κόμβων) είναι ένα εργαλείο σημασιολογικής εξερεύνησης: περιγράψτε τι έχετε διάθεση να δείτε, ή διαλέξτε μία από τις λίστες σας, και η βιβλιοθήκη σας σχεδιάζεται ως γράφημα με αφίσες όπου μπορείτε να περιπλανηθείτε.

## Πώς τον ανοίγετε

Επιλέξτε **Χάρτης περιεχομένου** στο πλαϊνό μενού. Χρειάζεται να έχουν δημιουργηθεί τα embeddings του AI — ο διαχειριστής σας πρέπει να έχει ολοκληρώσει τη ρύθμιση του AI.

---

## Πώς ξεκινάτε ένα γράφημα

Δύο τρόποι:

### Αναζήτηση με περιγραφή

Γράψτε τι ψάχνετε — *«ψυχολογικά θρίλερ»*, *«κωμωδίες που σου φτιάχνουν τη διάθεση»*, *«επιστημονική φαντασία που σου στραβώνει το μυαλό»* (οι ενδείξεις «Δοκιμάστε:» είναι παραδείγματα). Ψάξτε με διάθεση, θέμα ή περιγραφή, όχι με τίτλο. Οι πρόσφατες αναζητήσεις σας κρατιούνται για να τις ξαναχρησιμοποιήσετε με ένα κλικ.

### Περιήγηση σε μία από τις λίστες σας

Το **Περιήγηση ανά** ξεκινά το γράφημα από μια λίστα που ήδη έχετε: **Οι ταινίες που μου προτείνει το AI**, **Οι σειρές που μου προτείνει το AI**, **Σειρές που βλέπετε**, **Κορυφαίες ταινίες**, **Κορυφαίες σειρές**. Ο τίτλος #1 μιας λίστας σημειώνεται στον κόμβο του.

Όσο φτιάχνεται το γράφημα, η σελίδα περιγράφει τι κάνει — ψάχνει στη βιβλιοθήκη σας, βρίσκει θέματα, ομαδοποιεί, τακτοποιεί.

---

## Πώς διαβάζετε το γράφημα

- Οι **κόμβοι** είναι αφίσες· οι κεντρικοί/κύριοι τίτλοι εμφανίζονται μεγαλύτεροι. Το μέγεθος του κόμβου *δεν* δείχνει ομοιότητα
- Οι **ακμές** συνδέουν σχετικούς τίτλους· περάστε τον δείκτη πάνω σε μια ακμή για το **ποσοστό ομοιότητας**
- **Περάστε τον δείκτη πάνω σε έναν κόμβο** για τίτλο, έτος, τύπο και ετικέτες **«Συνδέεται μέσω:»**
- **Πατήστε μια αφίσα** για να γίνει το νέο κέντρο (με διαδρομή πλοήγησης που καταγράφει την πορεία σας)· **πατήστε ⓘ** (ή διπλό κλικ) για να ανοίξει η σελίδα της
- **Σύρετε** για να μετακινήσετε, **κυλήστε** για μεγέθυνση

### Χρώματα συνδέσεων

| Χρώμα | Σύνδεση |
|-------|-----------|
| **Μπλε** | Ίδιος σκηνοθέτης |
| **Κυανοπράσινο** | Κοινός ηθοποιός |
| **Χρυσό** | Ίδια συλλογή |
| **Μωβ** | Ίδιο είδος |
| **Ροζ** | Ίδια θεματική (λέξεις-κλειδιά) |
| **Πορτοκαλί** | Ίδια εταιρεία παραγωγής |
| **Πράσινο** | Ίδιο δίκτυο |
| **Γκρι** | Παρόμοια κατά το AI (ομοιότητα embeddings) |
| **Σμαραγδί** | Ανακάλυψη του AI (σκόπιμα ποικίλες επιλογές) |

Το υπόμνημα στο πλάι δείχνει την ίδια λίστα ζωντανά.

## Χειριστήρια

| Χειριστήριο | Τι κάνει |
|---------|-------------|
| **Ταινίες / Σειρές / Και τα δύο** | Φιλτράρει το γράφημα κατά τύπο |
| **Απόκρυψη όσων είδα** | Αφαιρεί τους τίτλους που έχετε ήδη δει |
| **Συνδέσεις ανάμεσα σε ταινίες και σειρές** | Αφήνει μια ταινία να συνδεθεί με μια σειρά που της μοιάζει και αντίστροφα (μόνο στις προβολές περιήγησης· μία θέση ανά τίτλο κρατιέται για τον άλλο τύπο) |
| **Από την αρχή** | Επαναφέρει το αρχικό γράφημα |
| **Ανανέωση** | Ξαναφτιάχνει το γράφημα με τις τρέχουσες ρυθμίσεις |

---

## Δημιουργία λίστας

Το κουμπί **Δημιουργία λίστας** στην κεφαλίδα παίρνει τους τίτλους που δείχνει τώρα το γράφημα και ανοίγει το παράθυρο της λίστας με αυτούς ήδη συμπληρωμένους («θα προστεθούν N τίτλοι») — δώστε όνομα, φτιάξτε προαιρετικά μια περιγραφή, και η λίστα δημιουργείται στον διακομιστή πολυμέσων σας. Δείτε τις [Λίστες](playlists.md).
