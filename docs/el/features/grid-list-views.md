# Προβολή πλέγματος και λίστας

Οι περισσότερες σελίδες καταλόγου έχουν δύο τρόπους εμφάνισης — **Προβολή πλέγματος** (αφίσες) και **Προβολή λίστας** (αναλυτικές γραμμές). Η επιλογή σας αποθηκεύεται για κάθε σελίδα, στον λογαριασμό σας.

## Πού υπάρχουν

| Σελίδα | Πλέγμα | Λίστα | Λίστα από προεπιλογή; |
|------|------|------|---------------|
| **Περιήγηση — Ταινίες** | ✓ | ✓ | |
| **Περιήγηση — Σειρές** | ✓ | ✓ | |
| **Περιήγηση — Πρόσωπα** | ✓ | ✓ | **Λίστα** |
| **Προτάσεις** | ✓ | ✓ | |
| **Πιο πολυπαιγμένα πρόσφατα** | ✓ | ✓ | |
| **Ανακάλυψη** | ✓ | ✓ | |
| **Ιστορικό προβολών** | ✓ | ✓ | |
| **Σειρές που βλέπετε** | ✓ | ✓ | |

Ο διακόπτης βρίσκεται στην κεφαλίδα κάθε σελίδας (εικονίδια πλέγματος ▦ / λίστας ≡, με τονισμένο το τρέχον). Κάθε σελίδα και καρτέλα κρατά τη δική της επιλογή· αποθηκεύεται στον λογαριασμό σας (με τοπική προσωρινή αποθήκευση για άμεση φόρτωση), οπότε κάθε συσκευή δείχνει την ίδια διάταξη.

Οι σελίδες των τίτλων έχουν μια δική τους σχετική προτίμηση — τον διακόπτη **Λίστα / Χάρτης** στην ενότητα **Συναφείς ταινίες / σειρές**.

## Προβολή πλέγματος

Αφίσες με ενδείξεις, προσαρμοσμένες σε κάθε σελίδα:

- Η **βαθμολογία σας με αστέρια** όταν περνάτε τον δείκτη, και το **σημάδι ότι το είδατε** παντού
- **Ένδειξη προόδου επεισοδίων** («8/24») για σειρές που έχετε ξεκινήσει
- **Σήματα κατάταξης** στις Προτάσεις και στα «Πιο πολυπαιγμένα πρόσφατα»· **ενδείξεις θεατών** στα «Πιο πολυπαιγμένα πρόσφατα»· **σήματα πηγής** και **κατάσταση αιτήματος** στην Ανακάλυψη
- Περνώντας τον δείκτη εμφανίζονται επιπλέον στοιχεία όπου μια σελίδα έχει (μπάρα συνέχειας στο Ιστορικό προβολών, αντίστροφη μέτρηση στις Σειρές που βλέπετε)

## Προβολή λίστας

Η ίδια αφίσα δίπλα σε μια γραμμή με λεπτομέρειες. Τι περιέχει η γραμμή εξαρτάται από τη σελίδα:

| Σελίδα | Η γραμμή προσθέτει |
|------|--------------|
| **Περιήγηση** | Έτος, βαθμολογία κοινότητας, είδη, περίληψη δύο γραμμών, τη βαθμολογία σας στην ίδια γραμμή· στις σειρές επιπλέον αν προβάλλεται ή έχει τελειώσει, πλήθος σεζόν και διακόπτη **Το παρακολουθώ** |
| **Προτάσεις** | Βαθμό ταιριάσματος και μπάρες **Ομοιότητα / Καινοτομία / Βαθμολογία**, γραμμή με τον λόγο, Δείτε το τρέιλερ, Προβολή στο TMDb |
| **Πιο πολυπαιγμένα πρόσφατα** | **Μοναδικούς θεατές**, **πλήθος προβολών**, βαθμολογία κοινότητας· στις σειρές επιπλέον επεισόδια που είδαν και μέση ολοκλήρωση % |
| **Ανακάλυψη** | Πλήρη στοιχεία (έτος, διάρκεια, είδη), περίληψη, βαθμό ταιριάσματος, ενέργειες αιτήματος |
| **Ιστορικό προβολών** | Πλήθος προβολών («3x», «5+» πάνω από πέντε), μπάρα συνέχειας με επεξήγηση %, ημερομηνία τελευταίας προβολής, ενέργειες διαχείρισης |
| **Σειρές που βλέπετε** | **Μπάρα διαθεσιμότητας επεισοδίων**, αντίστροφη μέτρηση για το επόμενο επεισόδιο, ένδειξη πηγής |

Όλες οι γραμμές της λίστας κρατούν τις ενδείξεις της αφίσας (το σημάδι ότι το είδατε, βαθμολογία, πρόοδο), οπότε δεν χάνεται τίποτα στην πιο πυκνή διάταξη.
