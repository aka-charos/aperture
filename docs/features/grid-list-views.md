# Grid & List Views

Most catalog pages offer two display modes — **Grid View** (posters) and **List View** (detailed rows). Your choice is remembered per page, per account.

![Browse Grid View](../images/features/browse-movies-grid.png)

![Browse List View](../images/features/browse-movies-list.png)

## Where Views Are Available

| Page | Grid | List | List default? |
|------|------|------|---------------|
| **Browse — Movies** | ✓ | ✓ | |
| **Browse — Series** | ✓ | ✓ | |
| **Browse — People** | ✓ | ✓ | **List** |
| **Recommendations** | ✓ | ✓ | |
| **Top Picks** | ✓ | ✓ | |
| **Discover** | ✓ | ✓ | |
| **Watch History** | ✓ | ✓ | |
| **Shows You Watch** | ✓ | ✓ | |

The toggle sits in each page's header (grid ▦ / list ≡ icons, the current one highlighted). Each page and tab keeps its own mode; it's saved to your account (with a local cache for instant load), so every device shows the same layout.

Detail pages have a related preference of their own — the **Related Movies / Series** section's **List / Graph** switch.

---

## Grid View

Posters with overlays, tuned per page:

- Your **star rating** on hover, and the **watched tick** everywhere
- **Episode-progress badge** ("8/24") for series you're partway through
- **Rank badges** on Recommendations and Top Picks; **viewer chips** on Top Picks; **source badges** and **request status** on Discover
- Hover reveals extras where a page has them (resume bar in Watch History, countdowns in Shows You Watch)

## List View

The same poster beside a row of details. What the row carries depends on the page:

| Page | The row adds |
|------|--------------|
| **Browse** | Year, community rating, genre chips, two-line overview, your rating inline; series add Airing/Ended status, season count, and an **Add to Watching** toggle |
| **Recommendations** | Match score and **Similarity / Novelty / Rating** bars, reason line, Watch trailer, View on TMDb |
| **Top Picks** | **Unique viewers**, **play count**, community rating; series add episodes watched and % avg completion |
| **Discover** | Full metadata (year, runtime, genres), synopsis, match score, request actions |
| **Watch History** | Plays chip ("3 plays" / "Rewatched"), resume bar with % tooltip, last-watched date, management actions |
| **Shows You Watch** | **Episode availability bar**, upcoming-episode countdown, source chip |

All list rows keep the poster overlays (watched tick, rating, progress) so nothing is lost in the denser layout.
